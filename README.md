# ATM Transaction Simulator

A simple Java console-based application that simulates basic ATM transactions.

## About the Project

The ATM Transaction Simulator allows users to verify their PIN and perform basic ATM operations such as checking balance and withdrawing money.

## Features

- PIN verification
- Check account balance
- Withdraw money
- Display remaining balance
- ATM menu
- Insufficient balance checking

## Java Concepts Used

- Scanner
- Variables and data types
- if-else statements
- while loop
- switch statement
- Console input and output

## Project Flow

1. Start the ATM application
2. Enter the PIN
3. Verify the PIN
4. Display the ATM menu
5. Select an operation
6. Perform the transaction
7. Display the updated balance
8. Return to the ATM menu or exit

## Technologies Used

- Java
- Visual Studio Code
- GitHub
- Java Console

## How to Run

1. Open the project in VS Code.
2. Open ATM.java.
3. Compile and run the program.
4. Enter the PIN.
5. Select an option from the ATM menu.
6. Follow the instructions shown on the console.
